Who Am I?

Hi! I’m Siddharth Mishra. I’m a Mathematics & Computing Undergrad from India. I like developing softwares and Reverse Engineering. There are several things that I’ve worked on in the past including but not limited to Operating Systems, Machine Learning, Compiler Development, Vulkan Graphics API & OpenGL Graphics API, Desktop Applications etc… In my free time I either work on my personal projects or solve some Reverse Engineering challenges from crackmes.one or some other sites.

What Am I Working On Nowadays?

I recently got selected into Google Summer of Code 2023 Program. I’m working with Rizin Organization this year, helping them uplift MIPS architecture to RzIL. There’s also one personal side project I’m working on to fill the time when I’m not working on Rizin. I barely get time to solve any challenges but I’m using this time to create a this personal tool that’ll help me in my future Reverse Engineering endeavours.

It’s easier to learn to walk backwards after you can run forward properly, i.e., A good Reverse Engineer is also a good Software Developer.

Current Goals?

At present I have two main goals. I must learn

  • Program Analysis &
  • Intermediate Languages

because these topics will help me build the personal tool I’m talking about.
