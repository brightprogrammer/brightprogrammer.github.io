Hi! Welcome to The Project Blue. This site is usually used for note-keeping. You've probably already read about me at the home page. 

Project Blue is the outcome of me trying to keep a stable blog for a very very long time. I've been jumping blogging platforms from blogger to wordpress to geeksforgeeks to medium, back to wordpress, to github pages using jekyll, hugo and then finally hexo. Yes! this blog uses hexo as its static site generator.

I finally feel I've found a nice blogging platform for me and I now wish to stay with this.
