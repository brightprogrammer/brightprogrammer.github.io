Posted on Sun, 9th January, 2022 Edited on Thu, 14th September, 2023 In osdev Disqus:

Introduction

Well, the title can be misleading. We will be eventually implementing our own ‘puts’ function but for now it’s not named puts. The function will be analogous to puts. This function will actually be to help us debug things. After this chapter we will be adding more and more features to our OS and we need a method to see if it worked or not. This method can be anything! For eg : changing the screen colour to red (for error) or blue (for success). We print an error message if something bad happens.

Since we don’t have anything to print to screen, we’ll have to create our own function to display some text. Yes that ‘abcd’ now needs to be drawn instead of just calling printf or puts. So we will create a method to draw characters on screen first and then use that to create a print function.

The Bitmap

We’ll use a bitmap to help us draw those characters. A bitmap will have an array of numbers and each bit in each number will be flagged in such a way that when you convert it into a 2D matrix of size say 8x16 or 8x8 pixels, it’ll look like a legit alphabet.

I already have found a repository that contains lots of bitmaps like this. We can use them in our project.

We will use this romfont. This is a 8x16 font. This means each row will have 8 pixels (8 bits or 1 byte) and there will be 16 such rows. If you look at the array carefully, you’ll notice there are 16 elements in each line. Each line corresponds to a character. You can also see how this font will look by searching for it’s image in the given repository.
