Well, the title can be misleading. We will be eventually implementing our own 'puts' function but for now it's not named puts. The function will be analogous to puts. This function will actually be to help us debug things. After this chapter we will be adding more and more features to our OS and we need a method to see if it worked or not. This method can be anything! For eg : changing the screen colour to red (for error) or blue (for success). We print an error message if something bad happens. 

Since we don't have anything to print to screen, we'll have to create our own function to display some text. Yes that 'abcd' now needs to be drawn instead of just calling `printf` or `puts`. So we will create a method to draw characters on screen first and then use that to create a print function.

We'll use a `bitmap` to help us draw those characters. A `bitmap` will have an array of numbers and each bit in each number will be flagged in such a way that when you convert it into a 2D matrix of size say 8x16 or 8x8 pixels, it'll look like a legit alphabet.

I already have found a [repository](https://github.com/spacerace/romfont) that contains lots of bitmaps like this. We can use them in our project.

Let's implement the `draw_character(...)` function.
```c
// draw a single character on framebuffer at given position
void draw_character(font_renderer_t* font_renderer, char c, uint32_t xpos, uint32_t ypos){
    uint8_t font_width = font_renderer->font.font_width;
    uint8_t font_height = font_renderer->font.font_height;

    // get bitmap for required character
    // NOTE : This assumes that width of font is 8 pixels
    uint8_t* font_bitmap = font_renderer->font.bitmap + c * font_height;

    for(uint32_t i = 0; i < font_height; i++){
        uint8_t row_bitmap = font_bitmap[i];
        for(uint32_t j = 0; j < font_width; j++){
            // calculate write address
            uint32_t write_addr = (xpos + j) + (ypos + i) * font_renderer->framebuffer.width;

            // if bit is set then fill foreground colour else fill background colour
            // 8 - j because of endianness of pc when compiling. Bits are stored in little endian format
            if(row_bitmap & (1 << (8 - j))){
                font_renderer->framebuffer.address[write_addr] = font_renderer->foreground_colour;
            }else{
                font_renderer->framebuffer.address[write_addr] = font_renderer->background_colour;
            }
        }
    }
}
```

```c
// The following will be our kernel's entry point.
void _start(struct stivale2_struct *stivale2_struct) {
  // Let's get the terminal structure tag from the bootloader.
    struct stivale2_struct_tag_framebuffer *framebuffer_tag;
    framebuffer_tag = stivale2_get_tag(stivale2_struct, STIVALE2_STRUCT_TAG_FRAMEBUFFER_ID);

    // Check if the tag was actually found.
    if (framebuffer_tag == NULL) {
        // It wasn't found, just hang...
        for (;;) {
            asm ("hlt");
        }
    }

    // prepare renderer
    font_renderer_t font_renderer = {0};

    // get address of framebuffer
    font_renderer.framebuffer.address = (uint32_t*)framebuffer_tag->framebuffer_addr;
    font_renderer.framebuffer.width = framebuffer_tag->framebuffer_width;
    font_renderer.framebuffer.height = framebuffer_tag->framebuffer_height;

    // get font data
    font_renderer.font.bitmap = get_font_bitmap_array();
    font_renderer.font.font_height = 16;
    font_renderer.font.font_width = 8;

    // set foreground and background colours
    // byte order is : 0x(alpha)(red)(green)(blue)
    font_renderer.foreground_colour = 0xff38ff6a;

    // string to print
    const char* str = "Misra OS";

    uint32_t xpos = 25, ypos = 25;
    for(size_t i = 0; i < 8; i++){
        draw_character(&font_renderer, str[i], xpos, ypos);
        xpos += 8;
    }

    // We're done, just hang...
    for (;;) {
        asm ("hlt");
    }
}
```

```c
    while(*(str + sz)){
```
