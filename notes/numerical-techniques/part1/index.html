Numerical Techniques Root Finding Notes

Tomorrow is my exam on numerical techniques and what better way to lear NT than by doing it!? Almost all of the blow methods follow the following points. To keep myself from repeating, I’ll mention them here :

  • Given an equation \(f(x) = 0\) for which we need to find roots for
  • Find \(a\) and \(b\) such that \(f(a)*f(b) < 0\) meaning \(f(a)\) & \(f(b)\) are of opposite signs.
  • Root will exist between these two points.
  • Methods will work better if there existed only one root in between these two selected points.
  • Below methods are only for roots with single multiplicity.

Iteration Method

  • Create update formula \(x_{n+1} = \phi (x_n)\) with \(n = 1, 2, 3, etc…\)
  • Consider an initial approximation \(x_0\) picked from selected range \((a, b)\)
  • Derivative of update function \(\phi (x)\) must be less than 1 for all values in selected range \((a, b)\), i.e \(\dfrac{d \phi (x)}{dx} < 1 , \forall \ x \in (a, b)\)
  • Iterate until first 3 or 4 decimal places become static
  • Rate of convergence depends on the update formula being used

Regula Falsi Method (False Position Method)

\[x = \frac{(a \times f(b) - b \times f(a))}{(f(b) - f(a))}\]

  • Put \(a\) & \(b\) and find \(x\)
  • Update the range depending on whether \(f(a) \times f(x) < 0\) or \(f(b) \times f(x) < 0\)
  • Keep performing these steps until 3 or four decimal places become static
  • Rate of convergence is 1

Secant Method (Chord Method)

\[ x_{n+1} = x_n - \frac{x_n - x_{n-1}}{f(x_n) - f(x_{n-1})}f(x_n) \]

  • Rest all rules are same as regula falsi.
  • After deciding initial range \(x_0\) and x1, directly find x2, x3, …
  • No need to check for \( f(x_n) \times f(x_{n-1}) \) sign
  • Rate of convergence is \( 1.618 \), i.e \( \dfrac{1+sqrt(5)}{2} \)

Newton Rhapson Method

\[x_{n+1} = x_n - \dfrac{f(x_n)}{f’(x_n)} \]

  • Need just one point to start
  • Order is 2 (fastest convergence)

Bisection Method

\[ x = \frac{a + b}{2} \]

  • \( a \) and \( b \) is decided by \( f(a) \times f(b) < 0 \)
  • Update values of \( a \) or \( b \) with values of \( x \) depending on whether \( f(a) \times f(x) < 0 \) or \( f(x) \times f(b) < 0 \)
    • If \( f(a) \times f(x) < 0 \) then set \( b = x \) and continue to next iteration.
    • If \( f(x) \times f(b) < 0 \) then set \( a = x \) and continue to next iteration.
  • Order is 1

Rate of convergence derivation for

  • Regula Falsi
  • Secant
  • Newton Rhapson
  • Iteration
  • Bisection is just 1, we know it
