Writing memory managers are a difficult task. We have two basic options. First one is that we implement a full blown Garbage Collector that can scan the entire stack and heap for possible memory regions having no reference stored anywhere anymore, other is we implement a Memory Checker that’ll check if allocated memory objects are free’d or not. A garbage collection system would surely help reducing memory footprint but that’ll also increase performance overhead.

In total I’ll try these two things because without trying we won’t know which method is the best!.

  • DynamicMemoryManager system that’ll provide garbage collector like properties.
  • StaticMemoryManager system that’ll provide static memory manager

One more thing we can do to reduce performance overhead is add a common interface of these two as
