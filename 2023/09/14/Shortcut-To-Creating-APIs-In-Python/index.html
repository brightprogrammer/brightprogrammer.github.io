Back Story

Recently I participated in a 24hr all night hackathon in my college where we had to address some machine learning problems. One of them was creating an attendance system where you just need an image or a video to mark that student as present for that day.

We decided to create the machine learning backend in python and frontend in simple HTML and javascript. We would send responses in JSON format and receive requests through an API. Now we needed to create an API quick as we don’t want to spend much time on just creating the backend and frontend.

So, this post will be on how I created a simple API in python quicky in less than 10 lines of code. This is for me for future references and also for those who need quick copy-paste like code to create simple API in an easy language for their backend.

Introduction

API (Application Progamming Inteface) is a term generally used for web interfaces. Basically, your whole application is divided into backend and frontend. The sole purpose of your frontend is to rendering things based on the data it recieves from backend. If backend gives you a 404 error, you show the 404.html page, if backend gives you a JSON with entries to be filled in a table, you display that JSON in tabular format by appending to a DOM (Document Object Model) element.

So, APIs are just what they sound like, they’re interfaces, they’re black objects that do spooky things. All you need to know about them is they’ll do what they say they can do. For eg, in my case, the frontend, when loaded, would request a specific URL that’ll fetch a JSON response containing information about attendance of all students enrolled in your college and then frontend will use that JSON to edit the DOM and append rows to a table element, something like this :

The * means it’ll allow all origins to pass, but you can be selective about it, like : *.myfrontend.in, meaning any website with name ending in myfrontend.in will be able to access your API calls. Being a cybersec guy, I can’t fail to notice one problem with this type of selection of origins. As an attacker, if I can get a domain with something ending in myfrontend.in, then I might be able to access your backend API and then try some evil things like using SQLi.
