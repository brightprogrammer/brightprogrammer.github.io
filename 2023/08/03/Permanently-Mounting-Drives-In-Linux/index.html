Permanently Mounting Drives In Linux

Posted on Thu, 3rd August, 2023 In tips Disqus:

After installing (or re-installing) Linux, your drives other than root may not be already mounted even if they are in ext4 format. To make them mount permanently to some location even after you reboot, you need to add them to /etc/fstab. First we need to get a few things before we modify this file.

Step 1 : Create A Mount Point

First you need to create a mount-point by creating an empty folder where your drive will be mounted.

Step 2 : Find Drive ID/Name

Drives in Linux start with names like /dev/sda, /dev/sdb, /dev/sdc, etc… They’ll have multiple partitions later on that look like /dev/sda1, /dev/sda2, etc…
