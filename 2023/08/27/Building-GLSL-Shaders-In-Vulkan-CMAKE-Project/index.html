Building GLSL Shaders In Vulkan CMAKE Project

Posted on Sun, 27th August, 2023 Edited on Tue, 12th September, 2023 In vulkan , glsl , cmake Disqus:

Introduction

Every graphics rendering project need a build system to compile shaders. I usually encounter some problems while trying to setup this build system. This time I created a CMake script (by compiling from different sources that I do not remember about) to compile all shaders in a given directory. This compiled output will then be placed in bin/Shaders (if your output directory is bin).

C23 now provides a way to embed binary files in source, so you can just compile your shaders first and then embed the binary files to your source files as byte array. Then when you release your program, you won’t need to worry about finding the proper path of shaders and other complications related to that.

How To Use?

I’ll explain how I’m using this at the moment. I have created a directory called Shaders that contains all the shaders that I’m going to use in my Vulkan project. I then place this CMakeLists.txt file in the Shaders directory and then just include this as a sub directory.

Every compiled shader will have an extra .spv appended to it’s name. This will denote that it’s a compiled SPIR-V shader program. Now I already know the name of shader I compiled so I know the name of compiled program and it’s path. I can now use any trivial method to include the compiled shader and create VkShaderModule objects for it.
