Syscall Tables

Sometimes while working on some challenge or binary you suddenly see a syscall instruction or an int 80h and you need to figure out what the value in $rax register corresponds to. In that case these syscall tables are quite useful.

Linux Syscall Tables

Linux syscalls don’t change over different versions unlike Windows.

  • Syscall Table for Linux x86_64
  • Syscall Table from Linux x86_32 Source Code (Kernel Version 4.17)
  • Syscall Table from Linux x86_64 Source Code (Kernel Version 4.17)
  • A Searchable Linux Syscall Table

Windows Syscall Tables

All of the following links take their data from json data present here but are more readable because they are in table format. Windows syscalls change with every new version.

  • Windows X86 System Call Table (NT/2000/XP/2003/Vista/2008/7/8/10)
  • Windows X86-64 System Call Table (XP/2003/Vista/2008/7/2012/8/10)

  • Windows x86-64 WIN32K.SYS System Call Table (XP/2003/Vista/2008/7/2012/8/10)
